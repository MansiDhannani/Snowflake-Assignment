# Snowflake-Assignment


This repository contains the implementation and screenshots for the Snowflake Tutorial Assignment.

## Questions

### Q1 — SnowSQL Login and Connection
Installation, connection verification, and session information.

### Q2 — Creation of Snowflake Objects
Creation and manipulation of databases, schemas, warehouses, tables, and stages.

### Q3 — Data Loading Using SnowSQL
Loading a CSV dataset into Snowflake using SnowSQL and verifying the loaded records.

### Q4 — Snowflake Time Travel
Creating a table, performing UPDATE and DELETE operations, and querying an earlier version using Time Travel.

### Q5 — Data Recovery Using Time Travel
Recovering accidentally deleted records using Snowflake Time Travel.
